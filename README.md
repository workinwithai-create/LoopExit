# LoopExit

Break the 8-bar trap. Expand a simple chord loop into a full structured arrangement with live instrument chairs.

Addresses the #1 struggle from X/music communities: producers stuck polishing 8-bar loops instead of finishing tracks. Provides constraints, sections, and grid-perfect exports so you can drop into a DAW and finish.

## Features
- BPM 60–180, key, 4-chord progression
- Live samples (pinned PreEight SHA drums, bass, piano)
- Lookahead scheduler on AudioContext clock
- Live changes while playing
- Export WAV (48kHz/24-bit, exact length, first transient at sample 0, seamless loop) + MIDI
- localStorage persistence

## Distinct from
RideEight, ChopFour, PreEight, HookGrid, etc. Focused on full arrangement expansion from loop, not single-section lifts.
